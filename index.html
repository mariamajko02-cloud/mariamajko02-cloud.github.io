Таблиці та зображення в HTML + fixed-фон

Прокрути сторінку вниз: фон має залишатися нерухомим (це працює через background-attachment: fixed).

Текст для прокрутки

Додай кілька абзаців, щоб сторінка прокручувалась. Під час прокрутки фон залишатиметься на місці, а текст рухатиметься поверх нього.

Таблиці створюються тегом <table>, рядки — <tr>, клітинки — <td>, а заголовки — <th>. Зображення вставляються тегом <img>.

Для ефекту “нерухомого фону” використовується CSS властивість background-attachment: fixed;.
